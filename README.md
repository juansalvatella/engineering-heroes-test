# What Engineering Superhero Are You?

A short personality quiz that reveals your engineering archetype, based on the
[engineering superheroes framework](https://review.firstround.com/how-to-spot-and-magnify-the-powers-of-your-engineering-superheroes/)
by **Patrick Shields** (via First Round Review).

## The Five Archetypes

| Archetype | Superpower |
|-----------|-----------|
| The Aquaman | Deep problem-solving across system layers |
| The Flash | Turning ideas into working software at extraordinary speed |
| The Priest | Creating order and elegance through principled code |
| The Spielberg | Intuitive understanding of what users need |
| The Paladin | Shielding the team while amplifying everyone's strengths |

## Getting Started

```bash
npm install
npm run dev
```

## Deploy to GitHub Pages

1. Push this repo to GitHub.
2. Go to **Settings > Pages** and set source to **GitHub Actions**.
3. Push to `main` — the workflow deploys automatically.
